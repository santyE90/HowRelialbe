# Data Sources

Automotive data sources have not yet been selected. Selection will occur only after source
coverage, licensing, provenance, update cadence, and known biases can be assessed. This
document does not endorse or imply the availability of any dataset.

Raw source material and processed datasets will remain separate. Transformations must be
reproducible, and every dataset will retain source provenance. Source-specific limitations,
licensing restrictions, missingness, and population coverage will be documented before the
data is used for analysis or modeling.
